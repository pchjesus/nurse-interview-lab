# 모의면접 분석 프롬프트 템플릿

아래 자료를 이 대화에서 사용할 권한과 개인정보 처리 동의를 먼저 확인한다. 제공되지 않은 자료는 사용하지 않는다. 결과는 Nurse Interview Lab의 `docs/JSON_SCHEMA.md`에 정의된 1.1 JSON 객체 하나로 출력한다. JSON 밖 설명이나 마크다운 코드 펜스는 출력하지 않는다.

- 실제 녹음에서 들리지 않은 말이나 시각을 만들지 않는다. 이해가 불확실한 발언과 화자는 명확히 표시한다.
- 녹음 속 화자를 고유 participantId로 구분하고 면접관·응시자·미확인을 지정한다. 이름만으로 동명이인을 합치지 않는다.
- 실제 질문에 questionId와 순서, 직무·인성·미분류 유형을 부여하고 질문지와의 일치 여부와 불확실성을 표시한다. 각 발언은 고유 utteranceId, 화자, 질문과 연결한다.
- 각 평가를 해당 응시자와 질문에만 연결하고 실제 발언 ID와 인용을 제시한다. 발언하지 않은 내용을 성과로 평가하지 않는다.
- 직무 질문은 임상적으로 정확한 점, 부족한 점, 그 이유와 보완 방법을 구분한다. 잘한 점에도 확인 가능한 간호학적 근거를 제시한다.
- 인성 질문은 질문 의도, 논리성, 구체성, 전문직 태도와 협력을 실제 발언에 근거해 평가한다. 확인되지 않은 병원의 인재상 적합성을 단정하지 않는다.
- 개선 답변은 원문이 아닌 제안으로 표시한다. 모의 평가를 병원 공식 점수나 합격 예측으로 표현하지 않는다.
- 실제로 확인한 교재·지침의 sourceId, 서지 정보 및 확인한 페이지를 연결한다. 확인하지 못한 자료·페이지·인용은 만들지 말고 누락 또는 미검증으로 표시한다. 분석자의 확인 표시가 앱의 독립 검증을 뜻하지 않는다.
- 객체형 장점·부족한 점은 content와 선택적 quote, utteranceIds, reason, nursingEvidence, importance, improvement, references(sourceId, pages, verified)를 사용한다. 문서의 필수 필드와 ID 참조를 모두 만족한다.
