# 외부 분석 결과 가져오기

이 앱은 AI 분석이나 자동 전사를 실행하지 않습니다. 별도의 도구에서 개인정보·녹음 및 교재 이용 권한을 확인한 뒤 분석하고, [JSON 규격](JSON_SCHEMA.md)에 맞는 개별 보고서로 저장하세요. 민감한 실제 데이터를 저장소나 이 프로젝트의 이슈에 올리지 마세요.

분석 시 질문과 화자 ID를 일관되게 지정하고, 실제 발언과 개선 답변을 구별하도록 요청하세요. 질문별 평가에는 `participantId`와 `questionId`를 모두 지정합니다. 직무 및 인성 질문이 섞이면 각 질문의 `type`을 지정합니다. 확인하지 않은 참고문헌·페이지·병원 인재상을 만들어 내지 말고 미검증으로 표시해야 합니다. AI 출력은 실제 전사 및 원자료와 대조해야 합니다.

면접 기록 탭에서 파일을 선택·드롭하거나 JSON을 붙여넣고 검증합니다. 참여자마다 기존 사람, 새 사람, 연결 없음을 선택한 뒤 가져옵니다. 동명이인은 ID로 구분하세요. 중복 reportId는 거부됩니다. 전체 백업은 설정 탭의 복원 기능을 사용하며 현재 데이터를 교체합니다.
